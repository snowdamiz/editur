# Editur landing page

Astro + Tailwind site for [Editur](https://github.com/snowdamiz/editur).

```sh
cd site
npm install
npm run dev
```

The production site is built for GitHub Pages at `/editur`, so the local preview lives at `http://localhost:4321/editur/`.

```sh
npm test      # production build + contract tests
npm run build
npm run preview
```
