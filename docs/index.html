                Continuous release · macOS, Windows, Linux
              


              
A small native editor for quick, focused file changes.


              

                Editur opens one file beside a lazy, keyboard-navigable tree, searches the project from a floating
                palette, and saves through conflict-checked atomic replacement. Nothing else is competing for the
                window.

editor.rs

              
Saving is the part that has to be right.

              

                Every write goes through conflict-checked atomic replacement. If the file changed underneath you,
                the save stops and asks first.
              


              

                
    
                  
  • 
                    
                    External edits never disappear. A changed file offers Reload, Save As, or
                      Cancel instead of overwriting.
                  
    • 
                  
  • 
                    
                    Line endings and permissions survive. LF and CRLF are preserved exactly as
                      found, and the file mode is left alone.
                  
    • 
                  
  • 
                    
                    Binary input is refused. Invalid UTF-8 never gets opened, so it can never be
                      written back mangled.
                  
    • 
                  
  • 
                    
                    One resident process. A later editur PATH forwards the target to
                      the running window and returns immediately.
                  
    • 
                


                

                  

                    
                    save.rs
                    
                    UTF-8
                  

                  
// The write is a rename, so a crash mid-save cannot
// leave a half-written file on disk.
let stamp = Metadata::read(path)?;
if stamp != opened_at {
    return Err(Conflict::Changed);
}

temp.write_all(buffer.as_bytes())?;
temp.persist(path)?;  // atomic

                

              


              

                The editor wraps long lines and scrolls vertically, so there is no horizontal scrollbar to chase.
                Closing the window exits completely, after the usual unsaved-change check.
              

            


            
            

              
search.rs

              
Search that stays out of the way.

              

                Recursive indexing does not start until your first non-empty project query. Opening a large
                repository costs nothing until you actually ask it something.
              


              

                

                  

                    
                    atomic
                  

                  
Filenames

                  
atomic_save.rssrc/

                  
Contents

                  
fn atomic_replace(&self)src/save.rs:118

                  
// atomic rename, never truncatesrc/save.rs:104

                  
Enter to open · Shift+Enter for previous

                


                
    
                  
  • 
                    
                    ⌘F in the file. Matches highlight live,
                      with Enter and Shift+Enter to walk them.
                  
    • 
                  
  • 
                    
                    ⌘⇧F across the project.
                      Results arrive grouped into filename and content matches.
                  
    • 
                  
  • 
                    
                    A lazy tree. The explorer reads directories as you expand them, not on
                      launch.

keybindings.json

              
VS Code muscle memory, or real modal editing.

              

                Two immutable profiles ship with the editor. Customize derives an editable profile from either one
                without copying the preset, and every change is saved atomically without touching your buffers or
                undo history.
              


              

                

                  VS Code profile
                  
Only the commands that exist

                  
Platform conventions for save, search, panes, and sidebar. Nothing is bound to a feature Editur
                    doesn't implement.

                

                

                  Vim profile
                  
Practical modal editing

                  
Normal, Insert, Replace, Visual character and line, and Operator-pending, with counts, text
                    objects, registers, and a safe Ex subset.

                

                

                  Recorder
                  
Up to four strokes

                  
Record logical chords and opt a single stroke into physical-key-position matching when layout
                    matters.

                

              


              

                

                  
                  keybindings.json
                  
                  Custom profile
                

                
{
  "profile": "vscode+",
  "bindings": [
    { "key": "cmd+k cmd+s", "command": "application.openKeyboardShortcuts" },
    { "key": "cmd+shift+f", "command": "search.searchProject" },
    { "key": "f12",          "command": "editor.goToDefinition" }
  ]
}

              


              

                Command palettes, multi-cursor editing, folding, refactoring, and arbitrary when
                expressions are intentionally absent. Terminal control keys fall through to the PTY unless you
                explicitly override one.
              

            


            
            

              
agent.acp

              
An agent sidebar that costs nothing until you open it.

              

                Nothing provider-related is inspected, provisioned, or launched until Agent is opened for the first
                time. Normal startup builds one titlebar toggle and stops there.
              


              

                
    
                  
  • 
                    
                    Cursor and Codex, pinned. Release builds ship one attested provider bundle
                      at an exact version, never a mutable package tag or a global install.
                  
    • 
                  
  • 
                    
                    Exact permission choices. Tool activity, supplied diffs, and cancellation
                      are rendered as the agent reports them.
                  
    • 
                  
  • 
                    
                    No telemetry, no stored transcript. Editur adds neither, and it never asks
                      for or stores provider credentials.
                  
    • 
                  
  • 
                    
                    Your buffer stays yours. A dirty file must be saved before a prompt, and an
                      external edit never overwrites unsaved work.
                  
    •

                Permission cards reduce accidental execution, but they are not an operating-system sandbox. Prompts
                and relevant project code are sent to the provider you select, under that provider's own terms and
                billing.
              

            


            
            

              
lsp.toml

              
Language servers you already installed.

              

                Editur never downloads a language server and never makes an LSP network request. It runs the
                binaries already on your PATH, lazily, per project.
              


              

                

                  Ctrl+Space
                  
Completion

                  
Plain-text completion from the server, with hover documentation after the pointer rests.

                

                

                  F8 · Shift+F8
                  
Diagnostics

                  
Walk to the next or previous diagnostic without leaving the keyboard.

                

                

                  F12 · ⌘-click
                  
Go to definition

                  
Jump straight to the definition, or open it in a split pane.

                

              


              

                Presets cover rust-analyzer, TypeScript Language Server, Pyright, gopls, and clangd; each one can be
                left on Auto, pointed at a custom executable, or turned off. Servers stop when their last document
                closes, and files above 5 MiB never start one.
