Editur

Open a file. Change it. Leave.

A small native editor for quick, focused file changes—launched from your terminal, drawn on Metal, Direct3D 12, or Vulkan.

Install

One line from the shell

Checksum-verified continuous releases for macOS, Linux, and Windows. No account wall. No project config.

install.sh 
$ curl --proto '=https' --tlsv1.2 -LsSf \
  https://raw.githubusercontent.com/snowdamiz/editur/release/install.sh | sh
PowerShell 
> irm https://raw.githubusercontent.com/snowdamiz/editur/release/install.ps1 | iex
Then run editur . Update with editur update

Workflow

Built for the quick change

One buffer. A lazy tree. Safe saves. Optional Cursor Agent when you need it—never until you open the sidebar.

01

Terminal-native

Launch with a path, reuse one resident window, exit when you close. Later editur PATH calls forward into the open process.

02

Search that stays out of the way

In-file find as you type. Project filenames and contents from a floating palette. Cmd/Ctrl+F · Cmd/Ctrl+Shift+F

03

Conflict-checked saves

Atomic replacement that refuses to silently overwrite an externally changed file. Reload, Save As, or Cancel—your call.

04

Syntax on demand

Rust and plain text ship embedded. Install more when you need them: editur syntax install typescript

05

Cursor Agent sidebar

Streamed replies, plans, diffs, and permission cards for the current project. Private to Editur—nothing agent-related starts until you open it.

Small enough to stay out of the way.

Editur is for the change you already know how to make—not another workspace to configure.
